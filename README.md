# Waarderingsspecialisten.nl

Responsieve statische website, gebaseerd op de aangeleverde PDF en de visuele richting van straval.nl.

## Lokaal starten

```bash
python3 start_app.py --port 8765
```

Open daarna `http://127.0.0.1:8765`.

## Publiceren

De site bestaat uit statische bestanden en kan rechtstreeks worden gepubliceerd via Netlify, Vercel, GitHub Pages of een bestaande webhostingomgeving. Vervang vóór publicatie de tijdelijke telefoonlink in `index.html` en koppel het contactformulier aan de gewenste mail- of CRM-dienst.
